Docker Networking

Classroom Guide

Understanding Docker networking in depth with real-world examples.

What is Docker Networking?

Docker networking enables communication between containers and external systems.

  • Bridge Networks
  • Host Networks
  • Overlay Networks
  • Macvlan Networks
  • None (Isolated) Networks

Bridge Network

Default network for standalone containers.


# Create a bridge network
docker network create --driver bridge my_bridge
                
                  graph TD;
                  A[Container A] -- Bridge --> B[Container B];
                  B -- Bridge --> C[Container C];
                  C -- External Network --> D[Internet];

Host Network

Bypasses Docker’s virtual network and uses the host network directly.


# Run container with host network
docker run --rm --network host nginx

NGINX Reverse Proxy

Use NGINX as a proxy to route requests to multiple backend containers.

                  graph TD;
                  User -->|HTTP Request| NGINX;
                  NGINX -->|Forwards| Backend1;
                  NGINX -->|Forwards| Backend2;
                

version: '3.8'
services:
  nginx:
    image: nginx
    ports:
      - "80:80"
    networks:
      - mynetwork
  backend1:
    image: mybackend
    networks:
      - mynetwork
  backend2:
    image: mybackend
    networks:
      - mynetwork
networks:
  mynetwork:

Frontend-Backend Private Connection

                  graph TD;
                  Frontend -- Private Network --> Backend;
                  Backend -- Private Network --> Database;
                

version: '3.8'
services:
  frontend:
    image: frontend
    networks:
      - internal_network
  backend:
    image: backend
    networks:
      - internal_network
  database:
    image: postgres
    networks:
      - internal_network
networks:
  internal_network:
    driver: bridge

Overlay Networks for Swarm

                  graph TD;
                  Worker1 -- Overlay --> Worker2;
                  Worker1 -- Overlay --> Worker3;
                

docker network create --driver overlay my_overlay

Conclusion

Understanding Docker networks is crucial for containerized applications.

Key Takeaways:

  • Use bridge for default networking
  • Host network for direct access
  • Overlay for Swarm mode
  • Macvlan for real IP assignment
