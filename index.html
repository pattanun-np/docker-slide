Types of Docker Networks

Docker provides multiple network types:

  • Bridge
  • Host
  • None
  • Overlay
  • Macvlan

Bridge Network

The default network type in Docker.

docker network create my_bridge
graph LR A[Container 1] -- Bridge -- B[Container 2]

Host Network

Bypasses Docker networking stack.

docker run --network host nginx
graph TD A[Container] -- Uses -- B[Host Network]

None Network

Completely isolates the container from networking.

docker run --network none alpine
graph TD A[Container] -- No Connectivity -- X[None]

Overlay Network

Used in Docker Swarm for multi-host communication.

docker network create -d overlay my_overlay
graph TD A[Host 1] -- Overlay -- B[Host 2]

Macvlan Network

Assigns a MAC address to the container.

docker network create -d macvlan --subnet=192.168.1.0/24 my_macvlan
graph TD A[Container] -- MAC Address -- B[Physical Network]

Inspecting Networks

Use Docker CLI to inspect networks.

docker network ls
                    docker network inspect my_bridge

Connecting Containers

docker network connect my_bridge container1
graph TD A[Container 1] -- Connected -- B[Bridge Network]

Conclusion

Understanding Docker networking is crucial for containerized applications.
